# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating, you agree to uphold a welcoming, inclusive, and respectful environment for everyone.

## Reporting

If you experience or witness unacceptable behavior, please contact the maintainers at **conduct@qforge.dev** (or open a private report via GitHub).

Reports will be reviewed promptly and kept confidential.
