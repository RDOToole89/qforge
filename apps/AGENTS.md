The Python engine is the product. `apps/` is a consumer. The 15-minute path is
`docs/guides/getting-started/first-run.md`. Freeze new visual-lab scope until

## What This Layer Is

```
qforge engine  →  apps/api (FastAPI)  →  apps/client (Expo / web)
     ↑                    ↑                      ↑
  source of truth    JSON HTTP contract    visualization + teaching UI
```

- `apps/api` is a thin HTTP wrapper over `run()`, `sweep()`, the experiment
  registry, stored results, and `bloch_math`. It must not grow orchestration.
- `apps/client` never imports Python. It talks to `http://localhost:8000/api`
  (`apps/client/src/lib/api.ts`).
- The circuit-builder TypeScript simulator is **pedagogical**. Qiskit / Aer
  remains the scientific source of truth.

## Connection Map (do not break)

These are the live wires. A package rename must keep every one of them green.

| Wire | Backend | Frontend | What must stay identical |
|------|---------|----------|--------------------------|
| HTTP JSON | `apps/api/routes/*.py` | `apps/client/src/lib/api.ts`, `lib/types.ts` | Paths, field names, status codes |
| Config schema | `ExperimentConfig.model_json_schema()` | configure UI + `GET /experiments/config-schema` | Pydantic JSON, not Python import paths |
| Registry | `get_experiment` / `list_experiments` | registry tab | Experiment **names** (`01_superposition`, …) |
| Bloch viz | `qforge.engine.bloch_math.compute_bloch_data` via `GET /api/bloch/{filename}` and `POST /api/bloch/sweep` | `experimentAdapter.ts` | Payload shape |
| Catalog codegen | `scripts/gen_frontend_constants.py` | `apps/client/src/generated/catalog.ts` | Regenerated bytes; do not hand-edit |
| Golden math | `scripts/gen_quantum_golden.py` + `bloch_math` | `apps/client/src/lib/quantum/__tests__/golden/` | FE math == BE math to ~1e-6 |
| Docker | `Dockerfile` copies `src/` + `apps/api/` | not in the image | API still boots; client is local/pnpm |

CI already enforces the codegen wire (job `codegen` in `.github/workflows/ci.yml`).
Frontend CI (`.github/workflows/ci-frontend.yml`) is a separate workflow.

## Bit-index convention (the silent breaker)

- Frontend and `bloch_math` after codegen: **qubit 0 = MSB** = leftmost bitstring character.
- Qiskit statevectors: **qubit 0 = LSB**. Codegen calls `reverse_qargs()` before emission.
- The `asym_product3` golden fixture exists so an index mismatch fails loudly.
- Do not "fix" the TS simulator to match Qiskit LSB without regenerating goldens
  and updating adapters. See `scripts/gen_frontend_constants.py` and
  `scripts/gen_quantum_golden.py`.

## Package-rename checklist (when implementing `src` → `qforge`)

The HTTP contract does not mention `src`. Only Python imports and comments do.

1. Rewrite imports in `apps/api/routes/{experiments,hardware,bloch}.py` and
   `scripts/gen_frontend_constants.py`, `scripts/gen_quantum_golden.py`.
2. Set Docker `PYTHONPATH=/app/src` so `import qforge` works with
   `--no-install-project`.
3. Comment paths in `apps/client/src/lib/types.ts` and golden tests may say
   `src/qforge/engine/models` — update those comments; do not change TypeScript types.
4. Prove the wires:

```bash
uv run python -c "from qforge import run"
uv run qforge list
uv run python scripts/gen_frontend_constants.py
uv run python scripts/gen_quantum_golden.py
git diff --exit-code -- apps/client/src/generated apps/client/src/lib/quantum/__tests__/golden
uv run pytest tests/integration/test_api_routes.py tests/engine/test_bloch_api.py
uv run uvicorn apps.api.main:app --port 8000   # then GET /api/health
```

Generated catalogs must be **byte-identical** if no physics changed. If they
drift, stop — that is a real contract break, not a formatting nit.

## Parked gaps (pick up after `from qforge import run`)

Resume from here. Do not start these during the rename PR.

### FE-1 — Two simulators
The circuit builder simulates in TypeScript (`useSimulator.ts`). The engine
simulates in Aer. Goldens prove **Bloch/correlator math** alignment on a fixture
set, not that the TS gate simulator equals Aer. When you resume: document this
in the client README in one paragraph; keep TS pedagogical; never silently
"fix" divergence by loosening golden tolerances.

### FE-2 — Hand-written TS types vs generated catalog
`apps/client/src/lib/types.ts` is hand-mirrored from Pydantic.
`apps/client/src/generated/catalog.ts` is generated. They can drift (example:
`ExperimentType` in types.ts is missing `batch_sweep`, which the catalog has).
When you resume: generate or test-assert the TS config types from
`ExperimentConfig.model_json_schema()`, or delete the duplicate.

### FE-3 — Expo is a web lab in a native shell
`'use dom'`, custom scrubbers, no `<input type="range">` — these are webview
workarounds. Native store shipping is not the audience. When you resume: decide
explicitly to stay Expo-web or extract a Vite web app. Do not add native
navigation chrome in the meantime.

### FE-4 — Bloch v5.1 measurement-basis toggle
Parked from the Bloch visualizer: X/Y basis on the 2-qubit view so Cluster
states show non-zero correlators. Still valid; not next.

### FE-5 — FastAPI as a library dependency
`fastapi` / `uvicorn` are required deps of the Python package even though the
engine runs without HTTP. When you resume: `qforge[api]` extra, keep Docker
installing that extra. Do not fold `apps.api` into the `qforge` package.

### FE-6 — EEC on hardware is logical topology
`entanglement_error_correlation` correlates a **logical** entanglement graph
with pairwise MI. On IBM hardware the coupling map is physical. The metric is
still a logical-structure probe. When you resume: say this in the visualizer
insight copy so experiment-mode users do not read it as a chip-topology plot.
