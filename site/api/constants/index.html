    Constants¶

    Core constants and validation functions for the quantum decoherence analysis framework.

    src.core.analysis.constants ¶

    Analysis Constants for Structured Decoherence Research

    Central Configuration & Defaults¶

    This module defines all numerical constants, tolerances, and default parameters used throughout the quantum decoherence analysis framework. Centralizing these values ensures consistency and makes the framework easy to tune.

    Research Standards¶

    All constants are chosen based on: - Statistical best practices (Jeffreys prior for uninformative priors) - Numerical stability (epsilon values for log safety) - Computational efficiency (bootstrap sample sizes) - Research reproducibility (fixed random seeds)

    Educational Framework¶

    These constants embody key principles from: - Bayesian statistics (prior selection) - Information theory (base-2 logarithms) - Bootstrap theory (sample size recommendations) - Quantum measurement theory (smoothing for shot noise)

    Attributes¶

    ALPHA = 0.5 module-attribute ¶

    Jeffreys prior parameter for categorical distributions. α = 0.5 provides uninformative prior for Bernoulli/categorical parameters. Used for smoothing probability distributions before entropy calculations. Reference: Jeffreys (1946), "An Invariant Form for the Prior Probability"

    EPS = 1e-12 module-attribute ¶

    Minimum probability value for numerical stability. Probabilities are clamped to [EPS, 1] before logarithmic operations. Chosen to avoid underflow in 64-bit floating point calculations.

    LOG_BASE = 2.0 module-attribute ¶

    Base for all logarithmic operations in information theory. Base-2 ensures all entropy measures are in bits.

    DEFAULT_BOOTSTRAP_B = 1000 module-attribute ¶

    Default number of bootstrap samples for confidence intervals. B = 1000 provides good balance between accuracy and computation time. For publication-quality results, consider B = 5000-10000. Reference: Efron & Tibshirani (1993), "An Introduction to the Bootstrap"

    FAST_BOOTSTRAP_B = 300 module-attribute ¶

    Fast bootstrap sample count for testing and development. Used in unit tests to maintain reasonable execution times.

    SLOW_BOOTSTRAP_B = 5000 module-attribute ¶

    High-precision bootstrap for critical research results. Use for final publication numbers and important hypothesis tests.

    CONFIDENCE_LEVEL = 0.95 module-attribute ¶

    Standard confidence level for interval estimation. 95% corresponds to α = 0.05 significance level.

    ALPHA_LEVEL = 1 - CONFIDENCE_LEVEL module-attribute ¶

    Significance level for hypothesis testing (α = 0.05).

    CONF_INT_DEFAULT = (2.5, 97.5) module-attribute ¶

    Default (lower, upper) percentile bounds for bootstrap confidence intervals.

    EEC_LAMBDA = 1.0 module-attribute ¶

    Distance decay parameter for topology adjacency matrix. A_ij = exp(-λ * d_ij) where d_ij is physical/logical distance. λ = 1.0 provides reasonable decay for typical qubit layouts.

    PP_TOP_K_MIN = 5 module-attribute ¶

    Minimum number of top pathways to track for persistence.

    PP_TOP_K_MAX = 32 module-attribute ¶

    Maximum number of top pathways to avoid exponential explosion.

    PP_MASS_THRESHOLD = 0.8 module-attribute ¶

    Probability mass threshold for adaptive top-k selection. Choose k such that top-k pathways capture ≥80% of total probability.

    PP_MIN_RUNS = 3 module-attribute ¶

    Minimum number of runs required for meaningful persistence calculation.

    CES_MIN_POINTS = 4 module-attribute ¶

    Minimum number of (n, SS) points needed for logistic fit.

    CES_MAX_QUBITS = 10 module-attribute ¶

    Maximum qubit count for complexity emergence analysis. Beyond this, 2^n becomes computationally prohibitive.

    TIKHONOV_LAMBDA = 0.001 module-attribute ¶

    Tikhonov regularization parameter for readout confusion inversion. Prevents numerical instability when inverting near-singular matrices.

    VALIDATED_CV_THRESHOLD = 0.33 module-attribute ¶

    Coefficient of variation threshold for 'validated' status. CI half-width ≤ 0.33 * metric_value indicates high precision.

    STATUS_BAND_WIDTH = 0.33 module-attribute ¶

    Status band width for validated status determination. Alias for VALIDATED_CV_THRESHOLD for registry compatibility.

    EXPERIMENTAL_CV_THRESHOLD = 0.5 module-attribute ¶

    Coefficient of variation threshold for 'experimental' status. Above this threshold, results are marked as 'unstable'.

    VALIDATED_MIN_SAMPLES = 100 module-attribute ¶

    Minimum number of samples for 'validated' status.

    EXPERIMENTAL_MIN_SAMPLES = 50 module-attribute ¶

    Minimum number of samples for 'experimental' status.

    UNSTABLE_MAX_SAMPLES = 20 module-attribute ¶

    Below this sample count, automatically mark as 'unstable'.

    SIGNIFICANCE_P_VALUE = 0.05 module-attribute ¶

    P-value threshold for statistical significance. Used in null hypothesis testing for structure detection.

    MAX_QUBITS_EXACT = 20 module-attribute ¶

    Maximum qubits for exact state vector calculations. Beyond this, use sampling approximations or specialized algorithms.

    MAX_OUTCOMES_EXACT = 2 ** 16 module-attribute ¶

    Maximum number of measurement outcomes for exact calculations. Corresponds to 16 qubits for binary measurements.

    GHZ_EXACT_TC_2QUBIT = 1.0 module-attribute ¶

    Exact total correlation for 2-qubit GHZ (Bell) state. TC = H(X₁) + H(X₂) - H(X₁,X₂) = 1 + 1 - 1 = 1 bit.

    GHZ_EXACT_TC_3QUBIT = 2.0 module-attribute ¶

    Exact total correlation for 3-qubit GHZ state. TC = 3 * 1 - 1 = 2 bits for ideal case.

    STRUCTURE_WEAK_THRESHOLD = 0.1 module-attribute ¶

    Weak evidence threshold for structured decoherence.

    STRUCTURE_MODERATE_THRESHOLD = 0.3 module-attribute ¶

    Moderate evidence threshold for structured decoherence.

    STRUCTURE_STRONG_THRESHOLD = 0.5 module-attribute ¶

    Strong evidence threshold for structured decoherence.

    CORRELATION_WEAK_THRESHOLD = 0.2 module-attribute ¶

    Weak correlation threshold for EEC and other correlation metrics.

    CORRELATION_MODERATE_THRESHOLD = 0.5 module-attribute ¶

    Moderate correlation threshold for EEC and other correlation metrics.

    CORRELATION_STRONG_THRESHOLD = 0.8 module-attribute ¶

    Strong correlation threshold for EEC and other correlation metrics.

    SCHEMA_VERSION = '1.0' module-attribute ¶

    Current schema version for all outputs. Must match the frozen v1.0 schema suite exactly.

    DEFAULT_TEST_SEED = 123456789 module-attribute ¶

    Default random seed for reproducible testing.

    PERFORMANCE_TEST_SEED = 987654321 module-attribute ¶

    Separate seed for performance benchmarking.

    NUMERICAL_TOLERANCE = 1e-10 module-attribute ¶

    Tolerance for numerical equality comparisons in tests.

    STATISTICAL_TOLERANCE = 0.01 module-attribute ¶

    Tolerance for statistical property tests (entropy bounds, etc.).

    SMALL_TEST_N = 3 module-attribute ¶

    Small qubit count for fast unit tests.

    MEDIUM_TEST_N = 5 module-attribute ¶

    Medium qubit count for integration tests.

    LARGE_TEST_N = 8 module-attribute ¶

    Large qubit count for stress tests (marked as slow).

    SMALL_TEST_SHOTS = 1000 module-attribute ¶

    Small shot count for fast tests.

    MEDIUM_TEST_SHOTS = 10000 module-attribute ¶

    Medium shot count for accuracy tests.

    LARGE_TEST_SHOTS = 100000 module-attribute ¶

    Large shot count for high-precision validation.

    MAX_COUNTS_DICT_SIZE = 2 ** 16 module-attribute ¶

    Maximum size for counts dictionaries before warning. Helps detect exponential memory explosion.

    DEFAULT_N_JOBS = -1 module-attribute ¶

    Default number of parallel jobs (-1 = use all cores).

    ENABLE_RESULT_CACHING = False module-attribute ¶

    Whether to enable result caching (disable for research to ensure freshness).

    Usage Examples¶

    Validating Measurement Data¶

    from src.core.analysis.constants import validate_counts_dict

# Valid measurement counts
counts = {"00": 100, "01": 200, "10": 150, "11": 50}
validated = validate_counts_dict(counts)
print(validated)  # {"00": 100, "01": 200, "10": 150, "11": 50}

# Invalid counts (will raise ValueError)
try:
    invalid_counts = {"00": -50, "01": 100}
    validate_counts_dict(invalid_counts)
except ValueError as e:
    print(f"Validation error: {e}")

    Working with Bitstrings¶

    from src.core.analysis.constants import n_qubits_from_counts, all_bitstrings

# Detect number of qubits
counts = {"000": 100, "111": 200, "001": 50}
n_qubits = n_qubits_from_counts(counts)
print(f"Number of qubits: {n_qubits}")  # 3

# Generate all possible bitstrings
all_outcomes = all_bitstrings(n_qubits)
print(f"All possible outcomes: {all_outcomes}")
# ["000", "001", "010", "011", "100", "101", "110", "111"]

    Using Framework Constants¶

    from src.core.analysis.constants import (
    ALPHA, CONF_INT_DEFAULT, MAX_TOP_K, TOPK_MASS_TARGET
)

print(f"Jeffreys prior: {ALPHA}")  # 0.5
print(f"Default CI bounds: {CONF_INT_DEFAULT}")  # (2.5, 97.5)
print(f"Max top-k pathways: {MAX_TOP_K}")
print(f"Mass threshold: {TOPK_MASS_TARGET}")

    Mathematical Background¶

    Jeffreys Prior Smoothing¶

    The framework uses Jeffreys prior smoothing with α = 0.5 to ensure:

    • Full Support: All 2^n possible outcomes have non-zero probability
    • Bias Reduction: Eliminates bias when many outcomes are unobserved
    • Deterministic Ordering: Lexicographic ordering prevents run-to-run drift

    Confidence Intervals¶

    Default confidence intervals use the (2.5, 97.5) percentile range, providing 95% coverage for bootstrap distributions.

    Top-K Analysis¶

    Top-k pathway analysis focuses on outcomes with significant probability mass, filtering noise from rare events while preserving structural information.
